# ceal-v0.76.1 Release Record

## Status

Prepared, not released. The candidate source repair is committed and branch CI
is green, but no `ceal-v0.76.1` tag, release workflow, public signed artifact,
stable-pointer update, installed update, or live Gateway proof is claimed yet.

## Intended Value

Make Agent-owned normal notification shutdown finish cleanly after a successful
v5 active-runner cancellation, without accepting an early FD5 loss or an
unrelated stream failure.

- Patch version `0.76.1`; planned canonical tag `ceal-v0.76.1`.
- Exact `ERR_STREAM_PREMATURE_CLOSE` classification only after Agent EOF has
  latched shutdown ownership.
- Real inherited FD5 owner-close, FD5-first, and same-message/wrong-code
  oracles.
- Protocol remains `0.72.13`; no public CLI, Gateway, or Agent source change.
